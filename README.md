# وب‌سایت برند عطر ZAREN

**BE REMEMBERED** — سایت استاتیک ساخته‌شده با React + Vite + TypeScript، مناسب انتشار روی هاست اشتراکی cPanel (پارس‌پک) بدون نیاز به Node.js روی هاست.

> ⚠️ **وضعیت تست:** این پروژه در محیطی نوشته شد که امکان نصب پکیج‌ها و اجرای `npm run build` وجود نداشت. بنابراین **Build و اجرای سایت هنوز تست نشده است.** اولین کار شما اجرای دستورهای بخش «اجرا روی کامپیوتر» است. اگر خطایی دیدید، متن کامل آن را برای توسعه‌دهنده/دستیار بفرستید تا رفع شود.

## ۱) ساختار پروژه

```
zaren/
├── index.html                  صفحه پایه (عنوان، توضیحات SEO)
├── package.json                فهرست پکیج‌ها و دستورها
├── vite.config.ts              تنظیمات Vite (base و خروجی dist)
├── tsconfig.json               تنظیمات TypeScript
├── public/                     فایل‌هایی که عیناً در dist کپی می‌شوند
│   ├── .htaccess               مسیریابی + HTTPS + کش (برای Apache/cPanel)
│   ├── favicon.svg
│   ├── robots.txt
│   ├── audio/                  موسیقی اختیاری (ambient.mp3)
│   └── images/products/        عکس‌های محصولات
└── src/
    ├── main.tsx                نقطه شروع، فونت‌ها، مسیریاب
    ├── App.tsx                 فهرست مسیرها (صفحات)
    ├── types.ts                نوع‌های داده (محصول، زبان)
    ├── config/site.ts          ⭐ تنظیمات: واتساپ، دامنه، تماس، موسیقی
    ├── data/products.ts        ⭐ اطلاعات محصولات
    ├── i18n/
    │   ├── translations.ts     ⭐ همه متن‌های فارسی و انگلیسی
    │   └── LanguageContext.tsx منطق تغییر زبان، جهت صفحه، قالب قیمت
    ├── components/             اجزای قابل استفاده مجدد (هدر، فوتر، کارت، دکمه واتساپ، موسیقی ...)
    ├── pages/                  صفحات: خانه، عطرها، جزئیات عطر، داستان، تماس، راهنما، ۴۰۴
    ├── hooks/                  هوک‌ها (عنوان صفحه)
    ├── utils/whatsapp.ts       ساخت لینک واتساپ و آدرس محصول
    └── styles/global.css       همه استایل‌ها
```

فایل‌های ستاره‌دار همان‌هایی هستند که شما بعداً ویرایش می‌کنید.

## ۲) اجرا روی کامپیوتر خودتان

### پیش‌نیاز
**Node.js** نسخه ۱۸ یا بالاتر (پیشنهاد: نسخه LTS ـ ۲۰ یا ۲۲) را از سایت رسمی `nodejs.org` نصب کنید.
برای اطمینان، در Terminal (ویندوز: Command Prompt یا PowerShell) بنویسید:

```
node -v
npm -v
```

باید شماره نسخه نمایش داده شود.

### مراحل
۱. پوشه پروژه (`zaren`) را باز کنید. در ویندوز: داخل پوشه، روی نوار آدرس کلیک کنید، `cmd` بنویسید و Enter بزنید.

۲. پکیج‌ها را نصب کنید (فقط بار اول؛ ممکن است چند دقیقه طول بکشد):

```
npm install
```

۳. سایت را در حالت توسعه اجرا کنید:

```
npm run dev
```

آدرسی مثل `http://localhost:5173` نمایش داده می‌شود؛ آن را در مرورگر باز کنید. برای توقف، `Ctrl + C` بزنید.

### ساخت خروجی نهایی

```
npm run build
```

اگر موفق باشد، پوشه **`dist`** ساخته می‌شود؛ همین پوشه است که روی هاست بارگذاری می‌شود.
برای دیدن نسخه نهایی روی کامپیوتر خودتان (اختیاری):

```
npm run preview
```

## ۳) تغییر اطلاعات سایت

### شماره واتساپ و اطلاعات تماس — `src/config/site.ts`
- `whatsappNumber`: شماره را با کد کشور و بدون `+` بنویسید، مثل `'989121234567'` (نوشتن `'09121234567'` هم پذیرفته می‌شود).
- تا وقتی خالی است، دکمه‌های سفارش یک پیغام «شماره هنوز تنظیم نشده» نشان می‌دهند. هیچ شماره‌ای از قبل داخل سایت نیست.
- `contact`: ایمیل، اینستاگرام، تلفن و نشانی. هر مورد خالی بماند، نمایش داده نمی‌شود.
- `showSampleNotice`: وقتی اطلاعات نهایی را وارد کردید، `false` کنید تا برچسب‌های «محتوای نمونه» حذف شوند.

### محصولات — `src/data/products.ts`
چهار محصول با اطلاعات **نمونه** وجود دارد. برای هر کدام نام، توضیح، نت‌ها، قیمت (تومان)، حجم (میلی‌لیتر) و تصاویر را بنویسید.
- قیمت یا حجم مشخص نیست؟ `null` بگذارید.
- محصول جدید: یک بلوک کامل را کپی کنید و `id` و `slug` تازه بدهید (`slug` فقط حروف انگلیسی کوچک و خط تیره).
- `isSample` را بعد از وارد کردن اطلاعات واقعی `false` کنید.
- عکس‌ها را در `public/images/products/` بگذارید و در `images` مسیرشان را بنویسید.

### متن‌ها — `src/i18n/translations.ts`
همه متن‌های ثابت سایت (فارسی و انگلیسی) اینجاست. هر کلید باید در هر دو زبان باشد.
متن «داستان برند» و «پرسش‌های متداول» فعلاً نمونه‌اند و باید با اطلاعات واقعی جایگزین شوند.

### موسیقی (اختیاری)
فایل `ambient.mp3` را در `public/audio/` بگذارید. موسیقی هرگز خودکار پخش نمی‌شود. اگر فایل نباشد سایت بدون خطا کار می‌کند.

## ۴) انتشار روی cPanel پارس‌پک (public_html)

۱. روی کامپیوتر خود `npm run build` را اجرا کنید تا پوشه `dist` ساخته شود.

۲. **محتویات** پوشه `dist` را (نه خود پوشه را) داخل یک فایل ZIP بگذارید:
   داخل `dist` شوید، همه چیز را انتخاب کنید (`index.html`، پوشه `assets`، `favicon.svg`، `.htaccess`، …) و ZIP کنید.
   > اگر فایل `.htaccess` در ویندوز دیده نمی‌شود، در File Explorer گزینه «Hidden items» را فعال کنید.

۳. وارد cPanel شوید ← **File Manager** ← پوشه **`public_html`**.

۴. در گوشه بالا روی **Settings** بزنید و گزینه **Show Hidden Files (dotfiles)** را فعال کنید (تا `.htaccess` دیده شود).

۵. اگر قبلاً فایل‌هایی در `public_html` هست (مثل صفحه پیش‌فرض هاست)، آن‌ها را پاک کنید یا ببرید به جای دیگر.

۶. **Upload** بزنید و فایل ZIP را بارگذاری کنید. سپس روی ZIP راست‌کلیک کنید ← **Extract**.
   مطمئن شوید `index.html` و `.htaccess` **مستقیماً** داخل `public_html` هستند، نه داخل یک زیرپوشه.

۷. فایل ZIP را پاک کنید.

### فعال‌سازی SSL (https)
۱. در cPanel به بخش **SSL/TLS Status** بروید (یا **Let's Encrypt / AutoSSL**، بسته به هاست).
۲. برای `zarenperfume.ir` و `www.zarenperfume.ir` گزینه **Run AutoSSL** را بزنید و چند دقیقه صبر کنید.
۳. فایل `.htaccess` پروژه به‌طور خودکار آدرس‌های `http://` را به `https://` هدایت می‌کند. **ابتدا مطمئن شوید SSL فعال شده، بعد سایت را تست کنید.** اگر SSL فعال نباشد، هدایت به https خطا می‌دهد.

### بررسی بعد از انتشار
- `https://zarenperfume.ir` باز می‌شود.
- از منو وارد «عطرها» شوید، سپس **صفحه را Refresh کنید** (F5). اگر صفحه باز شد، مسیریابی درست کار می‌کند.
- یک صفحه محصول را مستقیم در مرورگر باز کنید (مثلاً `/product/sample-01`).
- دکمه تغییر زبان و دکمه سفارش را امتحان کنید.
- سایت را روی موبایل هم ببینید.

### به‌روزرسانی سایت
هر وقت اطلاعات را عوض کردید: دوباره `npm run build` ← محتویات تازه `dist` را روی قبلی‌ها در `public_html` آپلود و جایگزین کنید. اگر مرورگر هنوز نسخه قدیمی را نشان داد، `Ctrl + F5` بزنید.

## ۵) رفع خطاهای متداول

| مشکل | علت و راه‌حل |
|---|---|
| `npm` شناخته نمی‌شود | Node.js نصب نیست یا Terminal را بعد از نصب نبسته‌اید. Node را نصب و Terminal را دوباره باز کنید. |
| `npm install` خطای شبکه می‌دهد | اتصال/فیلتر اینترنت. VPN یا یک mirror معتبر npm را امتحان کنید. |
| `npm run build` خطای TypeScript می‌دهد | متن کامل خطا (نام فایل و شماره خط) را بفرستید تا اصلاح شود. |
| صفحه سفید بعد از آپلود | معمولاً `index.html` داخل زیرپوشه است یا پوشه `assets` آپلود نشده. ساختار `public_html` را بررسی کنید. |
| با Refresh صفحه داخلی خطای 404 می‌دهد | `.htaccess` آپلود نشده/مخفی مانده است. **Show Hidden Files** را فعال و فایل را بررسی کنید. راه اضطراری: در `src/config/site.ts` مقدار `routerMode` را `'hash'` کنید، دوباره Build بگیرید و آپلود کنید. |
| خطای 500 بعد از آپلود `.htaccess` | بیشتر ماژول‌های Apache فعال‌اند؛ اگر هاست یکی را پشتیبانی نمی‌کند، بخش مربوطه را حذف کنید یا به پشتیبانی هاست بگویید. یا موقتاً `.htaccess` را حذف و `routerMode: 'hash'` را استفاده کنید. |
| هدایت بی‌نهایت (ERR_TOO_MANY_REDIRECTS) | معمولاً SSL از طریق پروکسی/Cloudflare انجام می‌شود. در Cloudflare حالت SSL را `Full` بگذارید. |
| فونت فارسی درست نمایش داده نمی‌شود | `npm install` کامل انجام نشده (پکیج‌های `@fontsource`). دوباره اجرا کنید و Build بگیرید. |
| دکمه موسیقی پیغام می‌دهد فایل نیست | `public/audio/ambient.mp3` را اضافه کنید و دوباره Build بگیرید. |
| سایت داخل زیرپوشه (مثلاً `/shop/`) است | در `vite.config.ts` مقدار `base` را `'/shop/'` کنید و در `.htaccess` مقدار `RewriteBase` را هم تغییر دهید. |

## ۶) آمادگی برای توسعه آینده

- **API / پنل مدیریت / موجودی:** کافی است `src/data/products.ts` با یک تابع `fetch` جایگزین شود؛ نوع `Product` در `src/types.ts` از قبل شناسه (`id`) دارد.
- **سبد خرید و پرداخت آنلاین:** دکمه واتساپ در یک کامپوننت جداست (`WhatsAppButton.tsx`) و می‌توان کنار آن دکمه «افزودن به سبد» ساخت.
- **زبان سوم:** نوع `Lang` و فایل `translations.ts` را گسترش دهید.
- در نسخه اول عمداً هیچ بک‌اند ایجاد نشده است.

## ۷) فهرست صادقانه آنچه تست نشده است

- `npm install` و `npm run build` اجرا نشده‌اند؛ هیچ ادعایی درباره موفق بودن Build وجود ندارد.
- کامپایل TypeScript، نمایش بصری در مرورگر (دسکتاپ/موبایل)، انیمیشن‌ها، تغییر زبان و جهت، فیلتر محصولات و رفتار دکمه موسیقی تست نشده‌اند.
- باز شدن واتساپ با پیام آماده تست نشده است (به شماره واقعی نیاز دارد).
- رفتار `.htaccess` روی هاست پارس‌پک واقعی تست نشده است.
- مسیر واردکردن فونت‌ها (`@fontsource/...`) از روی الگوی معمول پکیج‌ها نوشته شده و بدون نصب پکیج بررسی نشده است.
- همه اطلاعات محصولات، متن داستان برند و پاسخ پرسش‌ها **نمونه** هستند و اطلاعات واقعی نیستند.
